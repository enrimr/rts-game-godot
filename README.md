# Age of Kingdoms

An Age of Empires II inspired real-time strategy game built with [Godot 4](https://godotengine.org).  
Created by **Enrique Ismael Mendoza Robaina** ([@enrimr](https://github.com/enrimr)).

## Status

Early development — Milestone 1 in progress.

## Features (planned)

- Five civilizations with unique units and technologies
- Four resource types: Food, Wood, Gold, Stone
- Full Age progression: Dark → Feudal → Castle → Imperial
- AI opponents with configurable difficulty
- Multiple map types (Arabia, Black Forest, Islands, Gold Rush)
- LAN multiplayer (future milestone)

## Getting Started

### Prerequisites

- Godot 4.3 or later (standard build)
- Git

### Running the game

```bash
git clone https://github.com/enrimr/age-of-kingdoms.git
cd age-of-kingdoms
```

Open **Godot → Import** and select `project/project.godot`.

Press **F5** to run.

### Running tests

Install the [GUT addon](https://github.com/bitwes/Gut), then open the GUT panel inside the Godot editor and click **Run All**.
