# Headless & Renderer Harness Catalog

Every standalone harness under `project/tools/` (things GUT cannot easily reach:
scene loads, real-renderer screenshots, multi-process networking, long simulations).
This file is GENERATED from each harness's header comment — keep those comments
accurate and regenerate with the snippet at the bottom.

Run pattern (from the repo root):

```sh
GODOT=/Applications/Godot.app/Contents/MacOS/Godot
# headless harnesses:
$GODOT --headless --path project res://tools/<name>.tscn
# renderer harnesses (screenshots — need a display):
CALIMA_SHOT_DIR=/tmp/<dir> $GODOT --path project --resolution 1500x900 res://tools/<name>.tscn
```

The curated CI-gate subset (the ones that MUST pass before a merge) lives in
CLAUDE.md > Testing. Screenshot galleries from past reviews are kept under
`docs/design/` (unit-redesign-gallery, unit-enhanced-gallery).
