1 Identidad y propuesta de valor

El gancho existe y es real. Calima no es "otro clon de AoE2". Su ADN vive en dos sistemas que ningún indie del género combina.

🌪️ El clima como mecánica jugable, no decorativa

weather_manager.gd implementa cinco fenómenos canarios con modificadores medibles:

ClimaEfecto jugable
Calima−40% visión, −15% velocidad, −20% recolección (el más frecuente)
Tormenta Atlántica−50% pesca (¡puede matar de hambre a una civ naval!), deriva de proyectiles ±30px
Niebla MarinaCloaking costero real si intensidad ≥0.5 → stealth dinámico gratuito
Vientos AlisiosBono/penalización direccional naval (−20% a +20%) → micro naval emergente
Ceniza Volcánica2 HP/s de daño a todos los edificios → obliga a reubicar la base

El ramping de 10s de entrada/salida crea ventanas de timing para jugadas. Esto es diseño sistémico de verdad, no un filtro de pantalla.

⚔️ 16 héroes con variante de género — todos implementados

hero_unit.gd (823 líneas): Bencomo, Dácil, Doramas, Drake, Don Quijote, Cleito, Artaxerax… auras, conversión de enemigos a mitad de partida, dash de 400px, sniping, oleadas de marea curativas. Verificado: no son stubs, incluyen gestión de cooldown y limpieza de buffs al morir. La elección de género cambia la habilidad.

Sensación que transmite

Un RTS reactivo e impredecible anclado en un imaginario fresquísimo: Canarias prehispánica + Atlántida + conquista castellana. Guanches que cruzan el malpaís volcánico, Atlantes anfibios que cruzan el océano, Fenicios con Mercado desde la Edad Oscura. El tema está tejido en la mecánica, no pegado encima — lo más difícil de lograr, y aquí está conseguido.

Hooks virales / streamer-friendly
  • Niebla marina = emboscada invisible costera → clip viral inmediato.
  • Vientos alisios volteando una batalla naval → momento comentable.
  • Don Quijote cargando 400px a través de un ejército → GIF de tráiler.

Potencial desaprovechado

El clima no tiene bonus asimétricos por civilización (un "Atlantes ignora la tormenta" sería un combo civ×clima brutal y prácticamente gratis). El setting vive solo en los nombres: no hay campaña ni lore in-game que lo explote.

3 Código fuente y arquitectura

Veredicto técnico: base disciplinada y data-driven, pero con tres god objects que son el mayor riesgo de evolución.

Problema · Alta

hud_manager.gd — 3.312 líneas, 128 funciones, 12 arrays de acciones hardcodeados

Por qué importa: mezcla rendering, estado modal, colocación de edificios, timers, atajos y navegación DPad. Impacto: cada nueva unidad/edificio toca este archivo — cuello de botella de desarrollo. Solución: dividir en ActionMenuManager, ResourceDisplayPanel, TrainQueueUI, BuildingPlacementOverlay, TimerDisplayManager; mover las arrays (hud_manager.gd:28-120) a .tres/JSON → habilita modding.

Problema · Alta

IA acoplada al árbol de escena

ai_player.gd:26-29 referencia directa a units_layer/buildings_layer; 18+ get_children() directos en ai_military.gd, ai_construction.gd, ai_naval.gd. Impacto: reestructurar capas rompe toda la IA; cero abstracción. Solución: servicio WorldQuery inyectado (get_own_units(), get_enemy_buildings(), find_nearest_of_type()).

Problema · Media-Alta

map_generator.gd (2.610 l) y game_world.gd (1.973 l)

Terreno + shaders + spatial hash + spawn mezclados; selección + colocación + cámara + victoria mezclados. Solución: extraer TerrainPainter, EntityPlacer, MaterialManager, CameraController, UnitSelectionManager.

4 Relación diseño ↔ código

Sí, la arquitectura limita el diseño hoy:

  • El HUD hardcodeado frena el contenido. Añadir una unidad obliga a editar arrays dentro de 3.312 líneas. Un sistema data-driven de acciones desbloquearía prototipado rápido de unidades y modding.
  • La IA acoplada bloquea la iteración táctica. Probar nuevos comportamientos significa pelearse con get_children(). Un WorldQuery + comportamiento data-driven permitiría tunear la IA sin tocar el motor.
  • El clima está infrautilizado por falta de hooks de civ. La API de modificadores ya existe; falta un punto de enganche en civ_bonus_manager.gd para "esta civ ignora/aprovecha X clima". Bajo coste, alto impacto.
  • Sin command pattern → no hay base para replays, undo ni multijugador determinista. Es la deuda que decide el techo del proyecto.

7 Roadmap estratégico

Corto plazo — Quick wins (alto ROI)

  • Arreglar bonus dunas Mahos + implementar/retirar Wonder Victory.
  • Combos Civ × Clima — el combo identitario más barato del proyecto.
  • Minimap event-driven (fix de rendimiento real).
  • Tests de combate y recolección (el agujero más peligroso).

Medio plazo

  • Dividir hud_manager.gd en 5 managers + acciones data-driven.
  • Servicio WorldQuery para desacoplar la IA.
  • Extraer MeleeCombatUnit; terreno táctico (riscos/caldera).
  • Mini-campaña narrativa + accesibilidad.

Largo plazo

  • Command pattern → replays + base para multijugador determinista (M7).
  • Refactor de map_generator/game_world; soporte de modding.
  • ECS-lite si se superan ~500 unidades simultáneas.
