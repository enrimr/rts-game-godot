# Game Design Document — Age of Kingdoms

## Vision

A faithful spiritual successor to Age of Empires II: The Age of Kings, built in Godot 4. Single-player skirmish against AI, with multiplayer planned for a later milestone.

## Core Loop

1. Gather resources (Food, Wood, Gold, Stone)
2. Build a base and train an army
3. Research technologies to upgrade units
4. Advance through the Ages
5. Defeat enemy town centers / eliminate enemy player

## Civilizations (initial scope)

- Franks
- Britons
- Mongols
- Saracens
- Byzantines

Each civilization has 1–2 unique units, 1–2 unique technologies, and passive bonuses.

## Map Types

- Arabia (open land, low trees)
- Black Forest (dense forest, few openings)
- Islands (water-heavy, naval focus)
- Gold Rush (central gold deposits)

## Win Conditions

- **Conquest**: destroy all enemy Town Centers and unit-producing buildings
- **Wonder**: build a Wonder and survive for 200 years (game time)
- **Relics**: collect all relics and hold them for 200 years

## Milestones

| Milestone | Description |
|---|---|
| M1 | Playable map with villagers gathering resources |
| M2 | Town Center, Barracks, walls, and basic military |
| M3 | Full tech tree for one civilization |
| M4 | AI opponent |
| M5 | Five civilizations with unique content |
| M6 | Multiplayer (LAN) |
